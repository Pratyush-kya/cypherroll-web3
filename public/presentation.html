CRYPTOGRAPHIC PRIMITIVES • SHA-256 / HMAC

The Provably Fair Mathematical Engine

How CypherRoll guarantees zero manipulation, verifiable pre-commitments, and client-controlled randomness.

1

Server Seed Pre-Commitment

Before the user places a bet, the server generates a cryptographically secure 256-bit random hex seed ($S$) and sends only its SHA-256 hash ($H$) to the client.

$$H = \text{SHA-256}(S)$$

Because SHA-256 is preimage resistant, the server cannot change $S$ after seeing the player's wager or seeds.

2

Client Entropy Injection

The player provides a custom client seed ($C$) and an incrementing nonce ($N$). The casino has zero control over what client seed the player chooses.

$$\text{Payload} = C \parallel \text{“:”} \parallel N$$

Combined message space guarantees that even with a known server seed, results cannot be pre-computed by third parties.

3

Deterministic Outcome

The game result is computed by evaluating the HMAC-SHA256 using the secret server seed as the key over the client payload.

$$R = \text{HMAC-SHA256}(S, C : N)$$

First 8 hexadecimal characters are converted to an integer and mapped to the uniform float interval $[0, 1)$.

⚙️ The 32-Bit Hexadecimal Float Derivation Formula

To prevent statistical clustering, CypherRoll uses 4 distinct bytes ($b_0, b_1, b_2, b_3$) from the HMAC output, converting them into a high-precision 32-bit floating point number strictly distributed over $[0, 1)$:

$$\text{Float} = \frac{b_0 \cdot 256^3 + b_1 \cdot 256^2 + b_2 \cdot 256^1 + b_3 \cdot 256^0}{2^{32}}$$ $$\text{Float} = \frac{\text{parseInt}(\text{hex}[0..8], 16)}{4294967296}$$

$$X_i \sim \text{Bernoulli}(0.5), \quad i \in \{1, 2, \dots, N\}$$ $$\text{Landing Slot } S = \sum_{i=1}^N X_i \sim \text{Binomial}(N, 0.5)$$

🔔 2. Exact Binomial Distribution Formula

The probability $P(S = k)$ of the ball landing in slot index $k \in \{0, 1, \dots, N\}$ forms an exact symmetric binomial distribution:

$$P(S = k) = \frac{\binom{N}{k}}{2^N} = \frac{N!}{k!(N-k)! \cdot 2^N}$$

Center slots ($k \approx N/2$) possess enormous probability mass (up to 19.64% for $N=16$), while extreme edge slots ($k=0$ or $k=16$) have probability $\frac{1}{65536} \approx 0.001525\%$.
