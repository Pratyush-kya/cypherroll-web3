\section{Conclusion, Limitations, and Future Work}

\subsection{Summary of Technical Achievements}
This project successfully designed, implemented, and validated \textbf{CypherRoll}, an enterprise-grade, non-custodial Web3 crypto casino. By employing a 3-tier hybrid architecture:
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{High-Speed Interactivity:} Users enjoy responsive, hardware-accelerated 3D WebGL gameplay at 60 frames per second without incurring per-turn blockchain latency or transaction gas fees.
    \item \textbf{Mathematical Provable Fairness:} The HMAC-SHA256 commit-reveal mechanism guarantees complete post-game auditability and tamper-resistance, effectively resolving the trust deficit inherent to legacy centralized casinos.
    \item \textbf{Non-Custodial Settlement:} The Solidity escrow vault (\texttt{CypherRollVault.sol}) ensures players retain cryptographic claims over their deposits, with automated withdrawals authorized via EIP-712 typed structured signatures.
    \item \textbf{Seamless Testnet Verification:} Integration with Ethereum Sepolia and Base Sepolia enables zero-cost testing, auditing, and academic grading via MetaMask.
\end{enumerate}

\subsection{Limitations and Real-World Constraints}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Off-Chain Operator Liveness:} If the backend operator signer experiences downtime, instant EIP-712 withdrawal generation is delayed until operator nodes restore quorum.
    \item \textbf{RPC Rate Limiting:} Public JSON-RPC nodes on Ethereum Sepolia periodically throttle receipt inspection queries, necessitating dedicated paid endpoints (e.g., Alchemy or Infura) in high-traffic production environments.
\end{itemize}
