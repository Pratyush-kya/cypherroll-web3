    \vspace*{0.5cm}
    {\Large \textbf{ABSTRACT}\par}
    \vspace{0.8cm}
\end{center}

CypherRoll is a Web3-oriented online gaming platform designed around a hybrid execution model that separates responsive real-time game execution from blockchain-based non-custodial settlement. The project combines a modern Next.js and React application layer with Three.js/WebGL 3D hardware-accelerated visualization, wallet-based cryptographic authentication, cryptographic provable fairness, Supabase-backed relational persistence and real-time state synchronization, and an EVM escrow-vault smart contract component. The application implements two principal games---CypherDice and CypherCrash---along with a vault/cashier interface, live betting feed, community communication, support workflows, and an independent provably-fair verification interface.

The core cryptographic fairness mechanism employs a cryptographically secure server seed, a SHA-256 commitment published prior to bet placement, a player-controlled client seed, and a strictly incrementing nonce. HMAC-SHA256 deterministically derives game outcomes, allowing the revealed server seed and recorded inputs to be independently verified by players. The platform incorporates deterministic statistical testing, atomic wager balance mutations under concurrency, wallet signature authentication (Sign-In with Ethereum - EIP-4361 and Solana Wallet Adapter), real-time event broadcasting, and cryptographic withdrawal authorization via EIP-712 structured signatures.

The system architecture is structured as a three-tier hybrid model: presentation layer, application and game execution layer, and persistence/settlement layer. This decoupling addresses the latency and high gas-cost bottlenecks of executing high-frequency game state transitions directly on-chain, while preserving the cryptographic auditability and non-custodial security guarantees of decentralized ledgers.
