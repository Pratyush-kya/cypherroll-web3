\section{System Architecture and Technical Design}

\subsection{Architectural Paradigm: 3-Tier Hybridization}
CypherRoll is architectured according to a state-of-the-art \textbf{3-Tier Hybrid Web3 Architecture}. By decoupling presentation, fast off-chain state computation, and durable on-chain settlement, the system achieves the responsiveness of centralized web gaming while maintaining the cryptographic guarantees of decentralized ledgers.

\subsection{Component Decomposition}

\subsubsection{Tier 1: Presentation \& 3D Client Layer}
The user interface is powered by Next.js 14 utilizing the React Server Components (RSC) and Client Components paradigm. Hardware acceleration is achieved through Three.js:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{CypherDice 3D Scene:} Features physical lerping of curved polyhedral dice meshes with baked metallic/roughness PBR textures, reacting to deterministic roll outcomes.
    \item \textbf{CypherCrash 3D Flight Simulator:} Real-time particle thrusters, camera shake, and exponential flight curves synchronized with live game ticks.
    \item \textbf{Web3 Provider Layer:} Encapsulated within \texttt{Web3Providers.tsx}, managing Wagmi, RainbowKit, and TanStack React Query clients to provide connection states for MetaMask and other Web3 extensions.
\end{itemize}

\subsubsection{Tier 2: Application, Fairness \& Logic Layer}
Implemented within Next.js API Routes and Node.js cryptographic modules:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Authentication Guard:} Replaces vulnerable password authentication with EIP-4361 (SIWE). Challenge nonces are signed by the user's private key within MetaMask and verified using \texttt{viem/verifyMessage}.
    \item \textbf{Provably Fair Computation Engine:} Generates cryptographic server seeds with 256-bit entropy via \texttt{crypto.randomBytes(32)}, yields SHA-256 pre-commitment hashes, and derives deterministic game outcomes.
    \item \textbf{EIP-712 Withdrawal Signer:} Evaluates user payout requests against dynamic risk criteria and emits cryptographically signed withdrawal vouchers using the casino operator's private key.
\end{itemize}

\subsubsection{Tier 3: Persistence \& On-Chain Settlement Layer}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{PostgreSQL 16 ACID Ledger:} Hosted via Supabase, executing balance deductions and increments under strict transactional isolation. Row-level locks (\texttt{SELECT ... FOR UPDATE}) eliminate race conditions and double-spending attempts.
    \item \textbf{Smart Contract Settlement Vault:} The Solidity escrow contract (\texttt{CypherRollVault.sol}) deployed on EVM networks holds treasury reserves and executes autonomous, non-custodial payouts upon verifying the valid EIP-712 operator signature.
\end{itemize}
