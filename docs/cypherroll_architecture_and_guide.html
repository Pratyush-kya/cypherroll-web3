4. Provably Fair Cryptography: Math & Proofs

CypherRoll implements standard HMAC-SHA256 commit-reveal provably fair algorithms. The player never has to trust the operator:

1. Pre-Commitment

Before any round begins, the server creates a 256-bit cryptographically secure server seed:

ServerSeed = crypto.randomBytes(32).toString('hex')
ServerSeedHash = SHA256(ServerSeed)

The ServerSeedHash is publicly revealed in advance. The casino cannot change the outcome after you bet without altering this hash.

2. Outcome Calculation

When the user rolls, their outcome is calculated deterministically:

HMAC = HMAC_SHA256(key = ServerSeed, message = ClientSeed + ":" + Nonce)
HexChunk = HMAC.substring(0, 8)
Decimal = parseInt(HexChunk, 16)
RollOutcome = (Decimal / 4294967296) * 100

The platform sets an exact 1.0% house edge for Dice and 2.0% for Crash:
